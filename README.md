## 📄 Project Description
This project is a web-based application built using PHP Native and MySQL.
It was developed as a final project and portfolio to practice backend development concepts such as authentication, CRUD operations, and basic project structure.

## 🎯 Project Purpose
The purpose of this project is to:
- Practice backend web development using PHP Native
- Understand how a web application handles data and user interaction
- Build a simple but complete application for internship portfolio

## ✨ Features
- User login and registration
- CRUD functionality (Create, Read, Update, Delete)
- Database integration using MySQL
- Simple and responsive user interface

## 📂 Project Structure
- `public/` : main application entry point and UI
- `backend/` : application logic and data handling
- `config/` : database and application configuration
- `config_example/` : example configuration files
- `screenshots/` : application screenshots

## ⚙️ Environment Configuration
This project uses example configuration files for security purposes.
Please copy files from the `config_example/` folder and adjust them according to your local environment.

## 🚀 Installation & Setup
1. Clone this repository
2. Install dependencies using Composer:
   ```bash
   composer install
3. Import the database using data_aplikasi.sql
4. Configure database connection in config files
5. Run the project using a local server (XAMPP / Laragon)
